## 왜 만들었나

대학의 거의 모든 정보는 공지로 전달됩니다. 장학금 신청, 수강신청 정정, 졸업요건 변경 — 기한을 놓치면 회복이 어려운 정보들입니다. 그런데 그 공지가 모든 학생에게 똑같이 전달되지는 않습니다.

- 학생회와 학과가 올리는 공지 상당수는 **포스터 이미지 한 장**입니다. 스크린리더는 이 공지를 `"이미지"`라는 한 단어로 읽고 끝냅니다.
- **색으로만 구분한 정보**(빨강=마감, 초록=가능)는 적록색약이 있는 사람에게 거의 같은 색으로 보입니다. 한국 남성의 약 5%가 해당합니다.
- **연한 회색 본문**은 저시력·노안 조건에서 배경과 섞여 사라집니다.

이것은 태도의 문제가 아닙니다. 공지를 올리는 학생 대부분은 접근성 기준을 배운 적이 없고, **자기 공지가 읽히는지 확인할 방법도 없습니다.** 확인할 수단이 없으니 문제가 있다는 사실 자체를 알 수 없고, 알 수 없으니 고쳐지지 않습니다.

그래서 지적하는 대신 **30초 안에 스스로 확인하고 고칠 수 있는 도구**를 먼저 만들었습니다.

## 무엇이 들어 있나

| 기능 | 설명 |
|---|---|
| **명암비 검사기** | 두 색의 상대휘도를 계산해 WCAG 본문 AA(4.5:1)·AAA(7:1)·큰 글씨(3:1)·UI 요소(3:1) 충족 여부를 즉시 판정 |
| **시야 시뮬레이터** | 동일한 공지문을 저시력·적록색약·백내장/노안 조건으로 전환해 비교 |
| **스크린리더 낭독 비교** | 이미지 공지와 텍스트 공지가 각각 어떻게 읽히는지 대조 |
| **10문항 자가진단** | 공지 발행 전 점검 체크리스트와 점수 산출 |

의존성 없는 단일 HTML 파일입니다. 빌드 과정도, 외부 라이브러리도, 서버도 필요 없습니다.

## 계산 근거

명암비는 [WCAG 2.1 상대휘도 정의](https://www.w3.org/TR/WCAG21/#dfn-relative-luminance)를 그대로 구현했습니다.

```
L = 0.2126·R + 0.7152·G + 0.0722·B
  (각 채널: c ≤ 0.03928 ? c/12.92 : ((c+0.055)/1.055)^2.4)

명암비 = (L_밝은쪽 + 0.05) / (L_어두운쪽 + 0.05)
```

색각 시뮬레이션은 SVG `feColorMatrix`에 표준 변환 행렬을 적용한 **근사**입니다. 실제 지각과 동일하지 않으며, 색약 당사자의 검토를 대체하지 않습니다.
